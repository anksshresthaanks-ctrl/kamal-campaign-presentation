## 📋 विवरण (Description)

यो एक आधुनिक, इन्टरेक्टिव, एनिमेटेड प्रेजेन्टेशन हो जसमा कमल बहादुर श्रेष्ठको विकास योजना को १५ वटा स्लाइड छन्।

This is a modern, interactive, animated presentation with 15 slides covering Kamal Bahadur Shrestha's development plan for Kerawari Municipality.

## 🚀 कैसे उपयोग करें (How to Use)

### विकल्प 1: सीधे ब्राउजर में खोलें (Option 1: Open in Browser)

1. इस रिपोजिटरी को क्लोन करें:
```bash
git clone https://github.com/anksshresthaanks-ctrl/kamal-campaign-presentation.git
```

2. `index.html` को ब्राउजर में खोलें
3. आनंद लें! 🎉

### विकल्प 2: GitHub Pages (Option 2: GitHub Pages)

1. Settings में जाएं
2. Pages को enable करें
3. यह लिंक पर उपलब्ध होगा:
   ```
   https://anksshresthaanks-ctrl.github.io/kamal-campaign-presentation/
   ```

### विकल्प 3: मोबाइल में (Option 3: On Mobile)

1. इस लिंक को किसी भी डिवाइस में खोलें
2. या QR कोड को स्कैन करें (QR code will be provided)
3. Facebook, WhatsApp पर साझा करें
